# Firmware Flashing

## Instructions

If you need to update the firmware version of the ICRobot robot, please refer to this document for detailed instructions.

## Steps
|![](img/S1.png)||
|:-:|:-:|
|Step 1: Connect the device. Plug the ICRobot into the computer and power it on.||
|![](img/S2.png)|![](img/S3.png)|
|Step 2: Open the software and click “Select Device.”|Step 3: Choose “ICRobot.”|
|![](img/S4.png)|![](img/S5.png)|
|Step 4: Close the connection method directly.|Step 5: Select the “Firmware Burning” option.|
|![](img/S6.png)|![](img/S7.png)|
|Step 6: Choose the correct COM port for firmware burning.|Step 7: Select the firmware type to be flashed: Default Flashing — Standard firmware version. <br/>After selecting the desired version, click Upgrade.<br/>Note: If the selected firmware version name does not include the label “(Local Firmware)”, <br/>the computer must be connected to the internet during the flashing process.|
|![](img/S8.png)|![](img/S9.png)|
|Step 8: No further action is needed — wait for the firmware flashing to complete.|Step 9: No further action is needed — flashing is complete.|
