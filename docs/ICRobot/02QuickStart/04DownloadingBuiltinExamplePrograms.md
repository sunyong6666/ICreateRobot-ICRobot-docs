| **Step 5.** Open **"Examples"** and select **Python Examples**. Then select the built-in program you want to download. After selecting a program, its corresponding code will be loaded automatically into the editor.  <br/>**Note:** All five factory-installed built-in programs are included in **Python Examples**. In this guide, **Program <2>** is used as the demonstration example.   | **Step 6.** Download the program.<br/>In the **Download** section, select the target program slot, then click **Download**. Once the download is complete, the software will display **"Download Successful"**.<br/>**Note:Program <2>** is used as the demonstration example in this guide.   |
